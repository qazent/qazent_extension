# QAZent PR Assistant – Pricing

PR Assistant is offered under a simple, per-organization **Bring Your Own License (BYOL)** model from **[qazent.com](https://qazent.com)**. Checkout, billing, and license delivery are handled by **Lemon Squeezy** (Stripe). Activate your license in Azure DevOps under **Project Settings → QAZent - License**.

For licensing, billing, and activation help, see **[qazent.com/support](https://qazent.com/support)**.

## 14-Day Free Trial

Every new Azure DevOps organization gets a **14-day free trial** with full access to all features:

- QA mode and Code Review mode
- Unlimited PR analyses for your organization
- AI-generated test cases and review summaries from real code diffs
- Custom context (project and repository)
- Azure DevOps work items or PR comments
- No credit card required to start the marketplace trial

Your trial begins when you activate PR Assistant. After 14 days, an active license is required to continue.

## Standard Subscription

**Per organization — unlimited users.** No per-seat fees, usage caps, or hidden charges.

### Monthly — €9.99 / month

- Billed monthly per Azure DevOps organization
- Free for the first 14 days, then €9.99/month

### Annual — discounted yearly billing

- Same full feature set as monthly
- **Save up to 67%** compared with paying the monthly rate for 12 months
- Select **Annual** at checkout on [qazent.com](https://qazent.com) for the current yearly price

### Included in Standard (monthly and annual)

- Unlimited AI analyses from PR diffs, metadata, and commit messages
- QA mode (structured test cases) and Code Review mode
- Custom context per project and repository
- Azure DevOps work items and/or PR comment output
- Powered by Google Gemini 3.1 Pro (preview)
- Privacy-first processing (diffs and PR metadata only; not used for model training)
- Direct founder support
