# QAZent – Privacy Policy

**Last Updated: 2026-04-07**

This Privacy Policy explains how **QAZent** ("Company", "We", "Us", "Our") collects, uses, stores, and protects information when you install or use the **QAZent PR Assistant** extension ("Software") available through the Azure DevOps Marketplace.

By using the Software, you agree to the practices described in this Privacy Policy.

## 1. Information We Collect

We only collect information necessary to operate the Software and deliver its features. The Software processes the following types of data from your Azure DevOps environment:

### 1.1 Pull Request Metadata

- PR title
- PR description
- Linked work items
- Author and reviewer names (as provided by Azure DevOps)

### 1.2 Code‑Related Data

- Code diffs
- Modified files
- Added or removed logic
- Surrounding code context (when required for accurate AI generation)

### 1.3 Optional Custom Context

If you choose to provide it:

- Project‑specific rules
- Domain knowledge
- Testing conventions
- Architecture notes

### 1.4 Usage Data

We may collect anonymized or aggregated usage data such as:

- Feature usage frequency
- Error logs
- Performance metrics

This data **does not include your code or proprietary content**.

## 2. How We Use Your Information

We use the collected data solely to:

- Generate AI‑powered test cases
- Improve accuracy and relevance of generated content
- Provide support and troubleshooting
- Maintain and improve the Software
- Ensure security and operational integrity

We **do not** use your data for advertising, profiling, or unrelated analytics.

## 3. Data Storage & Retention

### 3.1 Code and PR Data

We do **not** permanently store:

- Your code
- Code diffs
- PR descriptions
- Work item content
- Custom context

These are processed **ephemerally** for the purpose of generating test cases and then discarded.

### 3.2 Logs and Telemetry

We may store:

- Error logs
- Performance metrics
- Aggregated usage statistics

These logs **never include your code or proprietary content**.

Retention periods vary based on operational needs but are kept only as long as necessary.

## 4. Data Sharing

We do **not** sell, rent, or trade your data.

We may share limited data with:

- **Third‑party AI model providers** (e.g., Google Gemini) strictly for generating test cases
- **Microsoft Azure DevOps services** as required for integration
- **Service providers** assisting with hosting, monitoring, or security

All third‑party providers are required to follow strict confidentiality and data protection standards.

## 5. Third‑Party AI Services

The Software uses third‑party AI models to generate test cases.
When doing so, the Software may send:

- Code diffs
- PR metadata
- Optional custom context

These providers process the data solely to generate output and do not retain it beyond their operational requirements.

Your use of the Software is also subject to the terms and privacy policies of these providers.

## 6. Security

We implement industry‑standard security measures to protect your data, including:

- Encrypted communication
- Secure API interactions
- Strict access controls
- No long‑term storage of code or PR content

However, no system is completely secure. You are responsible for maintaining the security of your Azure DevOps environment.

## 7. Your Rights

Depending on your jurisdiction, you may have rights to:

- Access your personal data
- Request deletion of personal data
- Correct inaccurate information
- Restrict or object to processing

Because we do not store your code or PR content, these rights generally apply only to:

- Account‑related information
- Support communications
- Telemetry data

To exercise your rights, contact us at **support@qazent.com**.

## 8. Children's Privacy

The Software is intended for professional use and is not directed at children under 16.
We do not knowingly collect personal information from children.

## 9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time.
Changes will be posted with an updated "Last Updated" date.
Continued use of the Software constitutes acceptance of the updated policy.
